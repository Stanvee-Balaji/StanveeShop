Add New Product

Create a single product entry via the POST /api/products endpoint.

Basic Information Required
Product name is required.
Must be unique across all products. Product ID is required.
Please select a stock status.
MRP is required (must be ≥ 0).
Offer price is required (must be ≥ 0).
Stock quantity is required.
Categories Required
Select at least one category.
Select at least one sub-category.
Images Required
A valid image URL is required.
Add at least one gallery image URL.
Descriptions Required
HTML supported: <ul>, <p>, <b>, <br> etc. Full description is required.
Short description is required.
Tax & Compliance Optional
Harmonized System Nomenclature for GST.

* Required fields must be filled before saving.
